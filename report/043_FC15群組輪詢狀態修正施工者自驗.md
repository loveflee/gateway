# 施工者自驗摘要（非最終驗收）

本報告只記錄 Codex 對 042 黑洞 G 的修復與自驗，**不是獨立驗收證據，也不構成 FINAL PASS**。依使用者要求，最終裁決必須等待 Claude Code 重新執行敵對式獨立驗收；AGENTS／README 尚未更新。

042 的死亡案例已在修改後正式 Gateway 重現並通過：

```text
group_234=all_off
→ FC05 switch_2=ON
→ 正常 FC01 0..7 poll
→ MQTT: switch_2=ON, group_234=__UNMATCHED__
→ FC05 switch_2=OFF
→ 下一次正常 FC01 poll
→ MQTT: 全部 OFF, group_234=all_off
```

更保守的是，單路 FC05 verify 當下只能讀一顆 coil，不能證明整組 vector；現在它已立即將受影響 group 標為 `__UNMATCHED__`，不再等待 15 秒 poll 才消除舊值。這不新增讀取、不做 read-modify-write，也不改變單路 FC05 wire contract。

## 資料流

```text
FC01 poll → 既有 bit decoder（switch_0..7）
          → 每個綁定同一 read command 的 coil_group exact matcher
          → named state 或 __UNMATCHED__
          → HA merged MQTT state
```

群組寫入的 full-board FC01 verify 繼續使用同一個 decoder。FC05 verify 保持既有 count=1 request；因只知道一顆 coil，group 僅發布 fail-closed sentinel，直到下一個整板 FC01 取得真實 vector。
